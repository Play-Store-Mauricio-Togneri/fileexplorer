Al descargar, instalar o usar File Explorer, usted acepta estar sujeto a estos Términos y Condiciones. Si no está de acuerdo con estos términos, por favor no utilice la aplicación.

Uso Permitido

Puede usar File Explorer para:

  • Explorar y navegar por el sistema de archivos de su dispositivo
  • Copiar, mover, renombrar y eliminar archivos y carpetas
  • Ver información y metadatos de archivos
  • Compartir archivos con otras aplicaciones
