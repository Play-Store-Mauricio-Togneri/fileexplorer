## Full description (3859/4000)

```
Pren el control dels teus fitxers amb File Explorer, el gestor de fitxers net, ràpid i intuïtiu pensat per a tothom. Tant si organitzes fotos com si gestiones baixades o alliberes espai, aquest potent gestor de fitxers t'ho posa fàcil.

<b>▸ NAVEGA AMB FACILITAT</b>
Recorre els teus fitxers sense esforç amb una interfície moderna i endreçada. La ruta de navegació et porta a qualsevol carpeta superior amb un sol toc. L'accés ràpid posa a mà les ubicacions que més fas servir: Baixades, Imatges, Vídeos, Àudio, Documents, Càmera, Captures de pantalla i Podcasts. Explora l'emmagatzematge intern, targetes SD i unitats USB OTG.

<b>▸ GESTIONA ELS TEUS FITXERS</b>
Tot el que necessites, res que sobri:
✓ Copia, mou, canvia el nom i elimina fitxers i carpetes
✓ Crea carpetes on vulguis
✓ Comparteix fitxers o obre'ls amb l'app que vulguis
✓ Instal·lador d'APK: instal·la aplicacions des de fitxers APK
✓ Selecció múltiple per a operacions per lots
✓ Ordena per nom, mida o data, ascendent o descendent
✓ Mostra o amaga fitxers i carpetes ocults
✓ Indicadors de progrés en operacions llargues
✓ Gestos de lliscament personalitzables: tria què passa en lliscar a esquerra o dreta

<b>▸ LA PRIVADESA, PRIMER</b>
File Explorer funciona sense connexió: no necessita internet i els teus fitxers no surten mai del dispositiu. Totalment gratuït, sense anuncis, compres dins l'app, subscripcions ni registre. Un gestor de fitxers que respecta la teva privadesa.

<b>▸ ANALITZA L'EMMAGATZEMATGE</b>
L'analitzador d'emmagatzematge integrat et mostra què omple el teu dispositiu, amb cada unitat desglossada per categories en un gràfic clar. Toca una categoria per veure'n primer els fitxers més grans i obre'ls o elimina'ls per alliberar espai.

<b>▸ TROBA-HO TOT AL MOMENT</b>
La cerca en temps real troba qualsevol fitxer pel nom mentre escrius, a l'emmagatzematge intern, targetes SD i unitats USB. Filtra per fitxers o carpetes, tipus de contingut o elements ocults per trobar just el que busques.

<b>▸ LECTOR DE PDF I VISUALITZADORS INTEGRATS</b>
Cap app per a un fitxer? File Explorer l'obre ell mateix: fitxers de text i codi, fotos amb zoom i GIF animats, PDF (amb cerca i suport de contrasenyes en versions recents d'Android), música amb caràtula i vídeo a pantalla completa, sense instal·lar res més.

<b>▸ COMPRIMEIX I EXTREU</b>
Gràcies al suport ZIP integrat, comprimeix fitxers per estalviar espai i compartir-los fàcilment. Descomprimeix arxius amb suport total per als protegits amb contrasenya. No cal cap altra app.

<b>▸ ELS PREFERITS, SEMPRE A MÀ</b>
Marca amb una estrella els fitxers i carpetes que més fas servir i t'esperaran a la pantalla d'inici de l'app, a un toc. Afegeix o treu preferits des de la llista de fitxers, els resultats de cerca o Recents, o esborra'ls tots alhora.

<b>▸ PREVISUALITZACIONS DETALLADES</b>
Mira més enllà del nom. Aquest gestor de fitxers genera miniatures d'imatges, fotogrames de vídeo, icones d'app per als APK, caràtules per a l'àudio, portades per als EPUB i gràfics SVG renderitzats.

<b>▸ INFORMACIÓ DETALLADA DELS FITXERS</b>
Obre els detalls de qualsevol fitxer per veure metadades segons el tipus: EXIF i GPS a les fotos, artista i àlbum a l'àudio, resolució als vídeos, i detalls de PDF, APK, arxius comprimits, documents i més.

<b>▸ FES-LA TEVA</b>
Adapta l'app a la teva manera de treballar: tria quines ubicacions mostra la seva pantalla d'inici i reordena'n les seccions, fixa una carpeta inicial, defineix què fan els lliscaments i què es veu sota cada fitxer, i desactiva els fitxers recents quan vulguis.

<b>▸ TEMES ELEGANTS</b>
Un aspecte modern amb Material Design 3 i tema Clar, Fosc o Per defecte del sistema. Cada pantalla llueix amb qualsevol llum.

<b>▸ PENSADA PER A TOTHOM</b>
Funciona amb Android 7.0 o posterior, en 20 idiomes. L'àrab i l'urdú tenen disposició de dreta a esquerra.
```
