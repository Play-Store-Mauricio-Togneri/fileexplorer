## Full description (1460/4000)

```
File Explorer 是一款简洁、快速、直观的文件管理器（资源管理器），专为所有人设计，助您轻松掌控自己的文件。无论是整理照片、管理下载内容，还是释放存储空间，这款强大的文件管理器都能让一切变得简单。

<b>▸ 轻松浏览</b>
现代、清爽的界面，让文件浏览毫不费力。借助路径导航栏，轻点一下即可直接跳转到任意上级文件夹。快速访问区把您最常用的位置——下载、图片、视频、音频、文档、相机、截图和播客——送到您的指尖。支持浏览内部存储、SD卡和 U盘（USB OTG）。

<b>▸ 管理文件</b>
所需功能一应俱全，多余功能一概没有：
✓ 复制、移动、重命名和删除文件及文件夹
✓ 随处新建文件夹
✓ 分享文件，或用您选择的任意应用打开
✓ APK 安装器：通过 APK 文件安装应用
✓ 多选项目，批量操作
✓ 按名称、大小或日期排序，支持升序和降序
✓ 自由选择显示或隐藏隐藏的文件和文件夹
✓ 耗时操作显示进度
✓ 可自定义滑动手势：自选向左或向右滑动时执行的操作

<b>▸ 隐私至上</b>
File Explorer 可离线使用：无需联网，您的文件绝不会离开您的设备。完全免费，没有广告、应用内购买和订阅，也无需注册。这是一款尊重您隐私的文件管理器。

<b>▸ 存储分析与空间清理</b>
看看是什么占满了您的设备：每个驱动器都按类别细分，以清晰的图表呈现。轻点某个类别，即可优先查看其中最大的文件，然后打开或删除它们，清理并释放空间。

<b>▸ 快速找到一切</b>
实时搜索会在您输入的同时按名称查找文件，范围涵盖内部存储、SD卡和 U盘。可按文件或文件夹、媒体类型或隐藏项目进行筛选，精准找到所需内容。

<b>▸ 内置 PDF 阅读器和查看器</b>
没有能打开某个文件的应用？File Explorer 自己就能打开：文本和代码文件、可缩放的照片和 GIF 动图、PDF（在较新的 Android 版本上支持搜索和密码）、带专辑封面的音乐，以及全屏视频，无需另外安装任何应用。

<b>▸ ZIP 压缩与解压缩</b>
内置 ZIP 支持，可压缩文件以节省空间，并轻松分享。解压 ZIP 压缩包时，全面支持受密码保护的文件。无需额外应用。

<b>▸ 常用收藏，触手可及</b>
为最常用的文件和文件夹加上星标，它们就会出现在应用的主屏幕上，一点即达。您可以在文件列表、搜索结果或最近文件中添加或移除收藏，也可以一次全部清除。

<b>▸ 丰富的预览</b>
不只是文件名。这款文件管理器会为图片、视频画面、APK 的应用图标、音频文件的专辑封面、EPUB 的书籍封面以及渲染后的 SVG 图形生成缩略图。

<b>▸ 详细的文件信息</b>
打开任意文件的详情，即可查看按文件类型呈现的元数据：照片的 EXIF 和 GPS 信息、音频的艺术家和专辑、视频的分辨率，以及 PDF、APK、归档文件、文档等的详细信息。

<b>▸ 随心定制</b>
按您的使用习惯定制应用：选择在应用主屏幕上显示哪些位置并调整板块顺序，选择启动文件夹，设置滑动操作以及每个文件下方显示的信息，还可以随时关闭最近文件。

<b>▸ 精美主题</b>
现代的 Material Design 3 外观，提供浅色、深色和跟随系统三种主题。无论光线如何，每个界面都同样出色。

<b>▸ 为每个人打造</b>
支持 Android 7.0 及以上版本，提供 20 种语言。阿拉伯语和乌尔都语采用从右到左的布局。
```
