## Full description (3991/4000)

```
Prendi il controllo dei tuoi file con File Explorer, il gestore file pulito, veloce e intuitivo pensato per tutti. Che tu stia organizzando foto, gestendo download o liberando spazio, questo potente gestore file rende tutto semplice.

<b>▸ NAVIGA CON FACILITÀ</b>
Sfoglia i tuoi file senza fatica con un'interfaccia moderna e ordinata. Il percorso di navigazione ti porta a qualsiasi cartella superiore con un solo tocco. L'accesso rapido mette a portata di mano le posizioni che usi di più: Download, Immagini, Video, Audio, Documenti, Fotocamera, Screenshot e Podcast. Esplora memoria interna, schede SD e unità USB.

<b>▸ GESTISCI I TUOI FILE</b>
Tutto ciò che ti serve, niente di superfluo:
✓ Copia, sposta, rinomina ed elimina file e cartelle
✓ Crea nuove cartelle ovunque
✓ Condividi i file o aprili con l'app che vuoi
✓ Installa app da file APK
✓ Seleziona più elementi per operazioni in blocco
✓ Ordina per nome, dimensione o data, crescente o decrescente
✓ Mostra o nascondi file e cartelle nascosti
✓ Indicatori di avanzamento per le operazioni lunghe
✓ Gesti di scorrimento personalizzabili: scegli cosa succede scorrendo a sinistra o a destra

<b>▸ PRIVACY PRIMA DI TUTTO</b>
File Explorer funziona offline: non richiede internet e i tuoi file non lasciano mai il dispositivo. Totalmente gratuito, senza pubblicità, acquisti in-app, abbonamenti né registrazione. Un gestore file che rispetta la tua privacy.

<b>▸ ANALIZZA LA MEMORIA</b>
Scopri cosa sta riempiendo il tuo dispositivo, con ogni unità suddivisa per categoria in un grafico chiaro. Tocca una categoria per vedere prima i file più grandi, poi aprili o eliminali per liberare spazio.

<b>▸ TROVA TUTTO IN UN ATTIMO</b>
La ricerca in tempo reale trova qualsiasi file per nome mentre digiti, nella memoria interna, nelle schede SD e nelle unità USB. Filtra per file o cartelle, tipo di media o elementi nascosti per trovare esattamente ciò che ti serve.

<b>▸ VISUALIZZATORI INTEGRATI</b>
Nessuna app per aprire un file? Ci pensa File Explorer: file di testo e codice, foto con zoom e GIF animate, PDF (con ricerca e supporto password nelle versioni recenti di Android), musica con copertina e video a schermo intero, senza installare nient'altro.

<b>▸ COMPRIMI ED ESTRAI</b>
Con il supporto ZIP integrato comprimi i file per risparmiare spazio e condividerli facilmente. Decomprimi gli archivi con pieno supporto per quelli protetti da password. Senza app aggiuntive.

<b>▸ PREFERITI SEMPRE A PORTATA DI MANO</b>
Metti una stella ai file e alle cartelle che usi di più e li troverai nella schermata principale dell'app, a un tocco. Aggiungi o rimuovi i preferiti dall'elenco dei file, dai risultati di ricerca o dai Recenti, oppure cancellali tutti insieme.

<b>▸ ANTEPRIME DETTAGLIATE</b>
Vai oltre il semplice nome. Questo gestore file genera miniature delle immagini, fotogrammi dei video, icone delle app per gli APK, copertine di album per i file audio e di libri per gli EPUB e grafica SVG renderizzata.

<b>▸ INFORMAZIONI DETTAGLIATE SUI FILE</b>
Apri i dettagli di qualsiasi file per vedere i metadati in base al tipo: EXIF e GPS per le foto, artista e album per l'audio, risoluzione per i video, più dettagli su PDF, APK, archivi, documenti e altro.

<b>▸ RENDILA TUA</b>
Adatta l'app al tuo modo di lavorare: scegli quali posizioni mostrare nella schermata principale e riordinane le sezioni, imposta una cartella iniziale, decidi cosa fanno gli scorrimenti e cosa appare sotto ogni file, e disattiva i file recenti in qualsiasi momento.

<b>▸ TEMI ELEGANTI</b>
Un look moderno in Material Design 3 con tema Chiaro, Scuro o Predefinito di sistema. Ogni schermata è perfetta con qualsiasi luce.

<b>▸ PENSATA PER TUTTI</b>
Funziona su Android 7.0 e successivi, in 20 lingue: arabo, bengalese, catalano, cinese, olandese, inglese, francese, tedesco, greco, hindi, indonesiano, italiano, giapponese, portoghese, rumeno, russo, spagnolo, turco, urdu e vietnamita. Arabo e urdu hanno layout da destra a sinistra.
```
