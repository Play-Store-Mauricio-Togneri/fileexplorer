## Full description (2113/4000)

```
File Explorerで、ファイルを思いどおりに管理しましょう。シンプルで高速、直感的に操作できる、誰でも使いやすいファイル管理アプリです。写真の整理も、ダウンロードの管理も、ストレージの空き容量の確保も、このパワフルなファイル管理アプリならかんたんです。

<b>▸ かんたんに閲覧</b>
モダンですっきりしたインターフェースで、ファイルをスムーズに閲覧できます。パンくずリストを使えば、上の階層のどのフォルダにもワンタップで移動できます。クイックアクセスには、よく使う場所（ダウンロード、画像、動画、オーディオ、ドキュメント、カメラ、スクリーンショット、ポッドキャスト）がそろっていて、すぐに開けます。内部ストレージ、SDカード、USBドライブを閲覧できます。

<b>▸ ファイルを管理</b>
必要な機能はすべてそろい、余計なものはありません：
✓ ファイルやフォルダのコピー、移動、名前の変更、削除
✓ どこにでも新しいフォルダを作成
✓ ファイルを共有、またはお好きなアプリで開く
✓ APKファイルからアプリをインストール
✓ 複数のアイテムを選択して一括操作
✓ 名前、サイズ、日付で並べ替え（昇順・降順）
✓ 隠しファイルとフォルダの表示・非表示を切り替え
✓ 時間のかかる操作は進行状況を表示
✓ スワイプ操作をカスタマイズ：左スワイプ・右スワイプの動作を選択

<b>▸ プライバシー第一</b>
File Explorerはオフラインで動作します。インターネット接続は不要で、ファイルが端末の外に送られることはありません。完全無料で、広告、アプリ内課金、サブスクリプション、アカウント登録は一切ありません。プライバシーを尊重するファイル管理アプリです。

<b>▸ ストレージを分析</b>
端末の容量を何が占めているのかを確認できます。ドライブごとの内訳が、カテゴリ別にわかりやすいグラフで表示されます。カテゴリをタップすると大きいファイルから順に表示され、そのまま開いたり削除したりして空き容量を増やせます。

<b>▸ すばやく検索</b>
リアルタイム検索なら、入力するそばから名前でファイルが見つかります。内部ストレージ、SDカード、USBドライブ全体が検索の対象です。ファイルかフォルダか、メディアの種類、隠しファイルで絞り込めば、目的のものがすぐに見つかります。

<b>▸ 内蔵ビューアー</b>
対応するアプリがないファイルも、File Explorerがそのまま開きます。テキストファイルやコードファイル、ズームできる写真やアニメーションGIF、PDF（新しいバージョンのAndroidでは検索とパスワードにも対応）、アルバムアート付きの音楽、全画面の動画まで、ほかに何もインストールする必要はありません。

<b>▸ 圧縮と展開</b>
ZIPに標準対応しているので、ファイルを圧縮して容量を節約したり、手軽に共有したりできます。パスワードで保護されたファイルにも完全対応し、アーカイブを展開できます。追加のアプリは必要ありません。

<b>▸ お気に入りをすぐそばに</b>
よく使うファイルやフォルダにスターを付けると、アプリのホーム画面に表示され、ワンタップで開けます。お気に入りの追加と削除は、ファイル一覧、検索結果、最近のファイルから行えます。すべてまとめて消去することもできます。

<b>▸ 充実のプレビュー</b>
ファイル名だけではありません。このファイル管理アプリは、画像、動画のフレーム、APKのアプリアイコン、オーディオファイルのアルバムアート、EPUBの表紙、レンダリングしたSVG画像をサムネイルで表示します。

<b>▸ 詳しいファイル情報</b>
ファイルの詳細を開くと、種類に合わせたメタデータを確認できます。写真ならEXIFとGPS、オーディオならアーティストとアルバム、動画なら解像度、さらにPDF、APK、アーカイブ、ドキュメントなどの詳細も表示されます。

<b>▸ 自分好みにカスタマイズ</b>
使い方に合わせてアプリを調整できます。ホーム画面に表示する場所を選んでセクションを並べ替えたり、起動フォルダを選んだり、スワイプの動作や各ファイルの下に表示する情報を設定したりできます。最近のファイルはいつでもオフにできます。

<b>▸ 美しいテーマ</b>
Material Design 3のモダンなデザインで、ライト、ダーク、システム設定のテーマから選べます。どんな明るさの場所でも、すべての画面が美しく表示されます。

<b>▸ すべての人のために</b>
Android 7.0以降で動作し、20言語に対応しています：アラビア語、ベンガル語、カタルーニャ語、中国語、オランダ語、英語、フランス語、ドイツ語、ギリシャ語、ヒンディー語、インドネシア語、イタリア語、日本語、ポルトガル語、ルーマニア語、ロシア語、スペイン語、トルコ語、ウルドゥー語、ベトナム語。アラビア語とウルドゥー語では右から左へのレイアウトで表示されます。
```
