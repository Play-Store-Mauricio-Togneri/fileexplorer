## Full description (3843/4000)

```
Держите файлы под контролем с File Explorer — лаконичным, быстрым и понятным файловым менеджером для всех. Разбираете фото, наводите порядок в загрузках или освобождаете память — этот мощный файловый менеджер и проводник всё упростит.

<b>▸ ЛЁГКАЯ НАВИГАЦИЯ</b>
Легко перемещайтесь по файлам в современном интерфейсе без лишнего. Строка пути ведёт в любую родительскую папку одним касанием. Разделы быстрого доступа держат под рукой самые нужные места — Загрузки, Изображения, Видео, Аудио, Документы, Камера, Снимки экрана и Подкасты. Просматривайте внутреннее хранилище, SD-карты и USB-накопители (USB OTG).

<b>▸ УПРАВЛЕНИЕ ФАЙЛАМИ</b>
Всё необходимое и ничего лишнего:
✓ Копируйте, перемещайте, переименовывайте и удаляйте файлы и папки
✓ Создавайте новые папки где угодно
✓ Делитесь файлами или открывайте их в любом приложении на выбор
✓ Установщик APK: устанавливайте приложения из APK-файлов
✓ Выделяйте несколько элементов для групповых операций
✓ Сортируйте по имени, размеру или дате, по возрастанию или убыванию
✓ Показывайте или прячьте скрытые файлы и папки
✓ Индикаторы прогресса для длительных операций
✓ Настраиваемые свайпы: выберите, что делает свайп влево или вправо

<b>▸ ПРИВАТНОСТЬ ПРЕЖДЕ ВСЕГО</b>
File Explorer работает офлайн: ему не нужно подключение к интернету, а ваши файлы никогда не покидают устройство. Полностью бесплатно: без рекламы, встроенных покупок, подписок и регистрации. Файловый менеджер, который уважает вашу конфиденциальность.

<b>▸ АНАЛИЗ ПАМЯТИ</b>
Встроенный анализатор памяти покажет, что занимает место на устройстве: каждое хранилище разбито по категориям на наглядной диаграмме. Нажмите на категорию: сначала идут самые большие файлы — откройте или удалите их, чтобы освободить место.

<b>▸ БЫСТРЫЙ ПОИСК</b>
Поиск в реальном времени находит любой файл по имени прямо во время ввода — во внутреннем хранилище, на SD-картах и USB-накопителях. Фильтруйте по файлам или папкам, типу медиа или скрытым элементам, чтобы найти именно то, что нужно.

<b>▸ PDF-РИДЕР И ВСТРОЕННЫЕ ПРОСМОТРЩИКИ</b>
Нет приложения для файла? File Explorer откроет его сам: текстовые файлы и код, фото с масштабированием и анимированные GIF, PDF (с поиском и поддержкой паролей в новых версиях Android), музыку с обложками альбомов и видео на весь экран — больше ничего устанавливать не нужно.

<b>▸ СЖАТИЕ И РАСПАКОВКА</b>
Встроенная поддержка ZIP позволяет сжимать файлы, чтобы экономить место и легко ими делиться. Распаковывайте архивы с полной поддержкой файлов, защищённых паролем. Дополнительные приложения не нужны.

<b>▸ ИЗБРАННОЕ ПОД РУКОЙ</b>
Отмечайте звёздочкой файлы и папки, которыми пользуетесь чаще всего, — они будут ждать вас на главном экране приложения, в одном касании. Добавляйте и удаляйте избранное из списка файлов, результатов поиска или недавних либо очистите его целиком.

<b>▸ НАГЛЯДНЫЕ МИНИАТЮРЫ</b>
Не только имена файлов. Этот файловый менеджер создаёт миниатюры изображений, кадры из видео, значки приложений для APK, обложки альбомов для аудиофайлов, обложки книг для EPUB и отображает SVG-графику.

<b>▸ ПОДРОБНОСТИ О ФАЙЛАХ</b>
Откройте сведения о любом файле, чтобы увидеть метаданные с учётом его типа: EXIF и GPS для фото, исполнитель и альбом для аудио, разрешение для видео, а также сведения о PDF, APK, архивах, документах и многом другом.

<b>▸ НАСТРОЙТЕ ПОД СЕБЯ</b>
Подстройте приложение под свой стиль работы: выберите расположения для главного экрана и порядок его разделов, папку при запуске, действия свайпов и то, что показывается под каждым файлом, а недавние файлы отключайте в любой момент.

<b>▸ КРАСИВЫЕ ТЕМЫ</b>
Современный стиль Material Design 3 в светлой, тёмной или системной теме. Каждый экран отлично выглядит при любом освещении.

<b>▸ ДЛЯ ВСЕХ</b>
Работает на Android 7.0 и выше, на 20 языках. Для арабского и урду интерфейс отображается справа налево.
```
